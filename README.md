## How to Run the Program

**Prerequisites:**
- Required compiler or interpreter installed.

**Steps:**
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Execute the program:

   ```bash
   Java Main
   ```

   For Windows, use:

   ```bash
   Java Main
   ```

## Features Implemented

- Add an expense with date, category, amount and a short note
- Set a monthly budget for each category
- Warn when a category crosses 80 percent of its budget, and again at 100 percent
- Show a month summary: total spent per category against budget
- List the 5 largest expenses of the month
